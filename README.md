# My To-Do List

A simple to-do list app built with plain HTML, CSS and JavaScript.
Tasks are saved in your browser, so they're still there after a refresh.

## Files

- `index.html` is the page structure
- `style.css` controls how it looks
- `app.js` makes it work

## Run it locally

Double-click `index.html` to open it in your browser.

## Deploy

Hosted on Vercel. Every push to the `main` branch on GitHub redeploys the site automatically.
